# Sprint attack and progression artwork

Sprint attack assets use original PLAYER root label47 (`dashpunch`, sprite737) and root label46 (`dashslam`, sprite736). Their source active timelines stop at frame12; sampled keys1,5,12 preserve the anticipation, attack and recovery pictures without extending gameplay duration. `dash_attack_art.h` samples0–2 are dashpunch and3–5 are dashslam. The renderer chooses local key0 before animation tick4, key1 before11, then key2. `dash_attack_frame` returns the shared `ArtFrame`; `dash_attack_decode` accepts sample, knight0–3, supported weapon0–3, and the existing actor decode buffer. It uses the already-established `knight_palette`, avoiding another palette/color conversion.

All blue, orange, red and green knights and supported weapons1,2,9,19 retain their actual source drawings. Shared body, color, weapon and corrective layers reduce96 complete source variants to21,351 bytes of static artwork/tables. Maximum decoded frame is2,516 pixels. `dash_attack_art_test.c` compares the full RGB555 source hash for every variant and verifies decoder bounds. The original full24-frame exports remain available locally for later quality/performance adjustments; adding sampled frames must respect the measured real DS headroom.

Source collision markers: sprite18 resolves to a31-source-pixel half-width/height square. Dashpunch first creates the marker on frame2 (DS center0.575,-21.725; half-size24.030,21.599 including root registration). Frame5 extends it to DS center22.075,-20.05; half-size44.498,21.598. Dashslam frame2 uses DS center23.075,-25.5; half-size33.527,25.618. Source dashpunch clears punching at7 and ends at12; dashslam ends at12. Combat simulation owns the precise timing and movement, independently of the sampled pictures.

Progression labels are source artwork, not a replacement font: PLAYER sprite29 contains LEVEL in font24; MAIN text342 contains New Combo. The former's runtime level number is intentionally blank in the image so the game can display the current number. `progression_art.h` contains just68x16 LEVEL and91x14 New Combo labels (523 bytes total including metadata/palette), bounded to1,274 decoded pixels. LEVEL is white with the original dark outline; New Combo uses the original black lettering and needs a light background. `progression_art_test.c` validates pixel hashes and bounds.

The original60-tick vertical level-up beam PLAYER30/31 is retained in the preparation/export workflow but is not in the default resident bank. `convert_progression_art.py --beam` is an explicit alternative for later in-world rendering; the default converter exports only the small labels. Regeneration order for dash: prepare/export, measure, factor, encode. Progression: prepare/export, convert. Previews are in `build/dash-attack-source-preview.png` and `build/progression-labels-preview.png`.
