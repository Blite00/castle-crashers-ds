# v0.63 QA
- Magic effects rebuilt from the original FX clips (tools/magic_fx.py, generated/magic_fx.h): animated bolts per element (poison 4 frames, fire 8, lightning, ice), the four impact bursts shown where a spell ends, per-element splash animations, frozen and burn effects, tinted ready glow and the original arrows. Pixels are run length packed and decoded into a 3 frame cache; translucent glow is ordered-dithered, so every effect uses the plain sprite blitter (no per-pixel alpha blending).
- Memory: effects art 105 KB plus alpha tables replaced by 66 KB packed; budget margin 88,580 to 111,812 bytes beyond reserves. Frame time was not measured on hardware.
- New level workflow: docs/new-level-workflow.md, tools/level_audit.py (registration audit) and tests/level_contract_test.c (collision, spawn, art edge, reachability, breakables), both run by check.ps1.
- Not verified: a run on DS hardware; impact bursts are client side and only appear for spells that vanish, not for shots absorbed off screen.
