# v0.50 Scalability foundation

- Weapon art no longer lives in the ROM image: `nitrofiles/weapons/w<slot>.bin` (held patches, heavy and dash keyframes) and `icons.bin` stream in when a weapon is equipped. Pixel output is identical to v0.49 (same source hashes: 7,296 held frames, 240 combo, 144 dash).
- Memory margin beyond the multiplayer reserves: 452,868 bytes (was 361,444).
- Wire (campaign protocol 41): weapon ids are 8-bit through a rotating byte; pets and level clears ride the same cycle. Pet ownership and weapon levels are no longer validated on the wire (host-only facts).
- Save v5 and a 64-byte guest profile message (the input reply grows from 36 to 64 bytes, far below the 227-byte DS limit). v1 to v4 saves migrate.
- Verification: check.ps1 48 PASS lines including weapon_art_test (pack corruption, slot independence), wire_ext_test (32-snapshot cycle, refused ids) and the rewritten pet_save_test.
- Untested on hardware: pack loads on equip (about 80 KB from SD) and the larger reply packet.
