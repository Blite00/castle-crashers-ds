# v0.44 boss meter

Boss and War Machine bottom-screen meter uses MAIN sprite 312 frame 25 (ornate frame, medallion, red bar) at 60% scale (154x31), 15 colors RLE in generated/boss_meter_art.h (842 run bytes). Red bar pixels beyond current health are dimmed. Tests: bottom_ui_test and hud_item_test count lit bar pixels at 100/50/0 percent for solo and co-op, host and guest, with canaries. Memory: campaign.c, hubs, save, feedback, bottom_ui, campaign_menu, item_selector, pets, campaign_war and campaign_boss compile with -Os pragma; 4,868 bytes beyond reserves.
